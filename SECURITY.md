# Security policy

## Supported version

Security fixes apply to the current `main` branch. This project does not promise support for unreleased branches unless its release policy says otherwise.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/astilbahq/astilba/security/advisories/new) for this monorepo. Include the affected package, version or revision, impact, and a minimal reproduction when possible. Existing released-package provenance remains bound to its original release repository until publisher cutover.

Do not disclose a suspected vulnerability in a public issue before it has been reviewed.
