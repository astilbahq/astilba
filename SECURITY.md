# Security policy

## Supported versions

Security fixes are released for the latest published version of `@astilba/env` and `@astilba/cache`. The web apps (the site, the docs at <https://astilba.com/docs> and the UI showcase) are fixed on `main`, which deploys on merge.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/astilbahq/astilba/security/advisories/new) for this monorepo. Include the affected package, version or revision, impact, and a minimal reproduction when possible.

Do not disclose a suspected vulnerability in a public issue before it has been reviewed.

Do not include secrets, access tokens, private configuration values or customer data in a public issue.
