# Security

Astilba is in technical validation and is not ready for production workloads. Run its experiments only on disposable infrastructure.

Report suspected vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/astilbahq/astilba/security/advisories/new). Include the affected revision, reproduction steps and impact, without live credentials or third-party private data. Do not disclose exploitable details in a public issue before coordination.
