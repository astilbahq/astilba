# Go control plane

Read the repository engineering principles. This module is the production control plane, separate from disposable experiments. Keep domain rules independent of HTTP and UI assets. `internal/httpapi` maps generated contracts to application operations; never serialize database account rows or encrypted values. Every tenant operation must establish workspace membership and the full nested project/environment identity. Membership writes lock the workspace before reading permissions. Specification rows are immutable; layout has a separate write path.

Use `pnpm generate` for OpenAPI/sqlc output. Never edit generated files. `make check-app` runs static checks and short tests; `make verify-app` needs an explicit disposable Docker socket and runs the database/browser gates. Keep tests focused on observable security, persistence and concurrency contracts. `internal/execution` owns server identities, plans and transactional River operations. `internal/deployment` owns the visual plan and its restricted Compose/Traefik rendering. `internal/agent` owns the host journal, probe and visual executors. Keep browser and agent authentication separate. Visual plans freeze images, secret references and observed state; secret values are hydrated only for the assigned deployment agent. Preserve ownership checks, retained data and verified ingress recovery. File-authoritative Compose uses the same execution boundary and keeps original bundles separate from runtime projections. Provider imports and build execution belong to P5.
